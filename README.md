## 📖 项目简介

UnravelChat是一个基于C++/Qt开发的现代化聊天系统，采用工程化设计标准。

## 🏗️ 当前项目结构UnravelChat/
├── client/                  # Qt客户端 (主要开发目录)
├── server/                  # 服务器端 (规划中)
├── email-service/           # 邮件服务 (规划中)
├── docs/                    # 项目文档
├── deploy/                  # 部署配置 (规划中)
